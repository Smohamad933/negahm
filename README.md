# نگاه مدیا | Negah Media

وب‌سایت و پنل مدیریت آژانس خلاق و تبلیغاتی **نگاه مدیا** — [negahm.ir](https://negahm.ir)

سایت کاملاً با **PHP 8.1+ و MySQL** نوشته شده و همه محتوای آن (برندها، نمونه‌کارها، خدمات،
متن‌ها، شبکه‌های اجتماعی و تنظیمات سئو) از **پنل مدیریت** کنترل می‌شود؛ هیچ بخشی از
محتوا در کد سخت‌کد نشده است.

### پنل مدیریت (`/admin`)

- **برندها** — افزودن برند، صفحه اختصاصی، لوگو، تصویر کاور، شبکه‌های اجتماعی و
  نمایش در نوار متحرک صفحه اصلی
- **نمونه‌کارها** — ثبت پروژه، اتصال به برند/دسته/خدمت، گالری چندتصویری،
  بخش‌های چالش/راه‌حل/نتیجه
- **خدمات، وبلاگ، صفحات دلخواه** — مدیریت کامل با ویرایشگر و سئوی مستقل
- **محتوای صفحه اصلی** — اسلایدر، آمار، مراحل همکاری، نظرات مشتریان، تیم و سوالات متداول
- **پیام‌ها** — صندوق ورودی فرم تماس با وضعیت خوانده/آرشیو
- **کتابخانه رسانه** — همه فایل‌های بارگذاری‌شده در یک جا
- **مدیریت منو** — ساخت/ویرایش/حذف آیتم، اتصال به هر موجودیت (صفحه، خدمت،
  نمونه‌کار، برند، نوشته، دسته‌بندی) یا آدرس دلخواه، زیرمنو، ترتیب با کشیدن،
  و برای هر آیتم به‌طور جدا: نمایش در دسکتاپ، نمایش در موبایل، باز شدن در تب جدید
- **فونت سایت** — بارگذاری فایل فونت از پنل (`woff2`/`woff`/`ttf`/`otf`) با
  بازهٔ وزن؛ فونت انتخابی هم‌زمان روی سایت و پنل اعمال می‌شود و با یک کلیک
  به فونت پیش‌فرض برمی‌گردد
- **آمار بازدید** — شمارش بازدید هر صفحه با عنوان خوانا، فیلتر بازهٔ زمانی
  (۷/۳۰/۹۰/۳۶۵ روز)، نمودار روزانه و پاک‌سازی داده‌های کهنه
- **کاربران** — نقش‌های `admin` و `editor`؛ ویرایشگر به محتوا دسترسی دارد و
  بخش‌های ساختاری (منو، فونت، کاربران، تنظیمات) فقط برای مدیر است
- **تنظیمات** — هفت گروه: عمومی، صفحه اصلی، درباره ما، تماس، شبکه‌های اجتماعی، سئو و سئوی صفحه‌ها
- **گزارش فعالیت** — ثبت خودکار همه تغییرات با کاربر و زمان

## نصب

### ۱. بارگذاری فایل‌ها

کل پروژه را روی هاست بارگذاری کنید. اگر می‌توانید **Document Root** را روی پوشه
`public` تنظیم کنید، این کار توصیه می‌شود. در غیر این صورت فایل `.htaccess` ریشه
همه درخواست‌ها را به `public` هدایت می‌کند.

### ۲. ساخت پایگاه داده

```sql
CREATE DATABASE negahm CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### ۳. اجرای نصب‌کننده

در مرورگر این آدرس را باز کنید:

```
https://yourdomain.com/install/
```

نصب‌کننده این کارها را انجام می‌دهد:

1. پیش‌نیازها را بررسی می‌کند
2. اطلاعات پایگاه داده و حساب مدیر را از شما می‌گیرد
3. `database/schema.sql` را اجرا می‌کند (۲۲ جدول)
4. `database/seed.sql` را اجرا می‌کند (محتوای اولیه شامل ۳۲ برند همراه)
5. رمز مدیر را با `password_hash()` رمزنگاری و ذخیره می‌کند
6. فایل `.env` را می‌سازد

> **پس از پایان نصب، پوشه `install` را حذف کنید.**

### نصب دستی (بدون نصب‌کننده)

```bash
mysql -u USER -p negahm < database/schema.sql
mysql -u USER -p negahm < database/seed.sql
cp .env.example .env      # سپس مقادیر را ویرایش کنید
```

### ۴. ورود به پنل

```
https://yourdomain.com/admin
```

| فیلد | مقدار پیش‌فرض |
| --- | --- |
| نام کاربری | `Mohusyn` |
| رمز عبور | `Smosh1387` |

> **بلافاصله بعد از اولین ورود، رمز را از «پنل ← پروفایل» تغییر دهید.**

### ۵. دسترسی پوشه‌ها

این پوشه‌ها باید برای وب‌سرور نوشتنی باشند:

```bash
chmod -R 775 public/uploads storage/logs storage/cache
```

## مسیرهای سایت

مسیرهای تمیز با `mod_rewrite` کار می‌کنند. اگر `mod_rewrite` در دسترس نبود،
همه صفحه‌ها با این حالت هم باز می‌شوند:

```
https://yourdomain.com/index.php?r=/brands
```

### نمونه تنظیم Nginx

```nginx
server {
    listen 80;
    server_name negahm.ir www.negahm.ir;
    root /var/www/negahm/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    location ~ /\.(?!well-known) { deny all; }
    location ~* \.(env|sql|log|md)$ { deny all; }

    location /uploads/ {
        location ~ \.php$ { deny all; }
    }
}
```

## اجرای تست‌ها

پروژه یک مجموعه تست خودکار دارد که برنامه را **واقعاً اجرا می‌کند**: درخواست‌ها از
`Router` عبور می‌کنند، میان‌افزارها و کنترلرها و قالب‌ها کار می‌کنند و خروجی HTML
بررسی می‌شود.

```bash
cd tools
npm install
npm test        # اجرای ۵۶ تست
npm run lint    # بررسی نحوی همه فایل‌های PHP
```

> **درباره پایگاه داده تست:** تست‌ها روی **SQLite** اجرا می‌شوند، چون در محیط
> توسعه به سرور MySQL دسترسی نیست. اسکیمای تست مستقیماً از روی خود
> `database/schema.sql` ساخته می‌شود (با یک لایه تبدیل در `tests/helpers/sqlite.php`)
> تا ساختار جدول‌ها هم پوشش داده شود. محیط واقعی سایت **MySQL/MariaDB** است و
> کوئری‌ها برای MySQL نوشته شده‌اند.

پوشش تست‌ها:

- تبدیل تاریخ جلالی و رفت‌وبرگشت آن
- ابزارهای متنی، اسلاگ یکتا و اعتبارسنجی
- ساخت پایگاه داده از `schema.sql` و بارگذاری `seed.sql`
- رندر همه صفحه‌های عمومی و بررسی محتوای آن‌ها
- پنهان‌بودن محتوای منتشرنشده
- فرم تماس: ثبت موفق، رد داده نامعتبر و فیلد ضدربات
- امنیت: CSRF، ورود ناموفق، قفل‌شدن موقت حساب و محافظت از مسیرهای پنل
- پنل: ساخت/ویرایش/حذف برند و نمونه‌کار، بارگذاری تصویر، گالری، تنظیمات
- اثرگذار بودن تنظیمات پنل روی صفحه‌های سایت
- مدیریت منو: ساخت/ویرایش/حذف، ترتیب، زیرمنو، تفکیک دسکتاپ و موبایل،
  و خوانده‌شدن عنوان و آدرس از رکورد متصل (صفحه، برند و …)
- فونت سایت: بارگذاری، فعال‌سازی انحصاری و تولید `@font-face`
- آمار بازدید: ثبت بازدید و نمایش آن در پنل

## سرور پیش‌نمایش

اگر در محیط توسعه نه PHP نصب است و نه سرور MySQL، می‌توانید سایت را با ابزار
`tools/serve.mjs` اجرا کنید. این ابزار **کد سایت را تغییر نمی‌دهد**؛ همان فایل‌های
PHP را داخل PHP-WASM اجرا می‌کند و پایگاه داده را از روی `schema.sql` و `seed.sql`
واقعی روی SQLite می‌سازد (همان مسیری که تست‌ها می‌روند).

```bash
cd tools
npm install
node serve.mjs          # پورت پیش‌فرض ۸۰۸۰ ؛ با PORT=9000 قابل تغییر
```

- ورود به پنل: `/admin/login` با `Mohusyn` / `Smosh1387`
- بارگذاری تصویر در پنل کار می‌کند و فایل‌ها زیر `/uploads/...` سرو می‌شوند
- پایگاه داده در حافظه است؛ با هر بار اجرای مجدد، از seed ساخته می‌شود

> این فقط برای پیش‌نمایش است. محیط واقعی سایت PHP-FPM/Apache + MySQL است و
> نصب واقعی از طریق `install/index.php` انجام می‌شود.

## نکات امنیتی

- همه کوئری‌ها با **Prepared Statement** اجرا می‌شوند
- توکن **CSRF** روی همه درخواست‌های تغییردهنده
- **`password_hash()`** با الگوریتم bcrypt برای رمزها
- **قفل موقت ورود** پس از ۵ تلاش ناموفق (۵ دقیقه)
- **محدودسازی نرخ** روی فرم تماس و ورود
- **فیلد ضدربات** (honeypot) روی فرم تماس
- پوشه `public/uploads` با `.htaccess` در برابر اجرای اسکریپت محافظت می‌شود
- فایل‌های `.env`, `.sql`, `.log` از وب مسدود شده‌اند
- هدرهای `X-Content-Type-Options`, `X-Frame-Options` و `Referrer-Policy`

### چک‌لیست پیش از انتشار

- [ ] پوشه `install` حذف شود

- [ ] `APP_DEBUG=false` باشد

- [ ] `APP_URL` روی دامنه واقعی تنظیم شود
- [ ] `public/uploads` و `storage` نوشتنی باشند
- [ ] گواهی SSL فعال و هدایت به HTTPS در `public/.htaccess` فعال شود
